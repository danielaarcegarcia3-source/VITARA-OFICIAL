# Medicamentos: encuadre derivado del activo original

`medicamentos-encuadrado.png` procede exclusivamente de `pastillasbotedeco.png`, que se conserva intacto en la raíz. Solo se recortó el margen transparente mediante el canal alfa (umbral 12/255) y se añadieron 16 píxeles transparentes de seguridad a cada lado. No se genera ni se sustituye el frasco; no se altera su etiqueta ni se le atribuye aprobación sanitaria. Se utiliza como ilustración decorativa, nunca como recomendación de medicamento ni fotografía de stock.
